description: "Why it is off by default and what you accept by turning it on."

<Note>This page is not written yet. Today there is nothing to turn on: LinkedIn steps are tasks a person performs ([LinkedIn](/docs/senders/connect-linkedin)). When an automated adapter ships it will be off by default behind the `channel:linkedin_auto` flag, require a per-sender written opt-in, cap invitations per day and week, and pause on any restriction signal. Turning it on means accepting that automated actions can get a sender's LinkedIn account restricted.</Note>
