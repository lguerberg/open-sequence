What the service does today: every email carries `List-Unsubscribe` and `List-Unsubscribe-Post` headers, `{{ unsubscribe_url }}` renders a one-click opt-out page, an opt-out always exits and suppresses, hard bounces and complaints suppress, and sends go through each sender's own Gmail account under its own reputation and daily caps.</Note>
