The building blocks exist: `GET /v1/schema` (the JSON Schema plus the node and channel catalogue with params and transitions), `GET /v1/schema/fields` (the condition picker), `GET /v1/schema/events`, `POST /v1/sequences:validate` (problems with JSON paths while the user edits), the draft's `lock_version`, and the [journey](/docs/enrollments/journey) to highlight a contact's path. No layout is stored in the definition; compute positions with a tidy-tree layout from `entry` and `next`.</Note>
